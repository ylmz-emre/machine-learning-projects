# Data directory

The project expects the private source files below in this directory:

- `MaterialAttributes_full.xlsx`
- `PLM Çalışması - Mara.xlsx`
- `PLM_Codes.xlsx`
- `PLM_MULTI_VAL_CHAR.xlsx`

These files are excluded by `.gitignore` and should not be committed if they contain proprietary or confidential master data.

You can also keep the files elsewhere and set the `DATA_FOLDER` environment variable to that directory.
